optimize-headline - Generate and evaluate headline/title alternatives for any content.

USAGE
  /optimize-headline        Resolves the target content (confirms it if already
                             named, asks if not), reads it (or the draft title),
                             applies the
                             headline redline rules, and generates 3 ranked
                             alternatives drawn from the pattern library (Number-led,
                             Alert, Threat Frame, Thesis Reversal, Uncomfortable
                             Question, Scenario Setup), with a recommendation.

  /optimize-headline --help  Prints this summary. Takes no other action.

See the full skill file for the complete pattern library and redline rules.
