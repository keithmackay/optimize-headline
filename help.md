optimize-headline - Generate and evaluate headline/title alternatives for any content.

USAGE
  /optimize-headline        Resolves the target content (confirms it if already
                             named, asks if not), establishes the target medium,
                             reads the content (or the draft title), applies the
                             headline redline rules, and generates 3 ranked
                             alternatives drawn from the pattern library - twelve
                             patterns across three registers, see SKILL.md for
                             templates and examples - with a recommendation, or a
                             "keep current" verdict if the baseline already wins.

  /optimize-headline --help  Prints this summary. Takes no other action.

See the full skill file for the complete pattern library, redline rules, and
per-platform length guidance.
